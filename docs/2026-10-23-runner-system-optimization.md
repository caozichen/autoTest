# Runner 历史存储、更新合并与资源观察优化

本文记录 autoTest 内存优化的实现与隔离验证阶段，保留完整历史 JSON、接口返回形状、业务执行规则、断言通过标准、并发上限、终态与取消规则。该阶段未修改表单产品仓库及业务 UI 脚本断言，没有重启已有 Runner 或恢复暂停的旧监控。后续已按用户要求安全重启 Runner，并完成 TEST 两套配置与资源监控，见[真实环境验证报告](2026-10-23-test-config-resource-monitor.md)。

## 实现

- `RunRecordFileStore.records` 常驻列表摘要，详情按需加载。详情使用 LRU，同时受 4 条与 32 MiB JSON 体积限制；超限记录只在当前操作使用，不进入缓存。对外详情仍返回独立副本，调用者不能修改缓存。
- 完整记录保持原有 JSON 文件路径与 schemaVersion 1。新增 `.summaries/` 可重建索引，以文件大小、mtime、ctime 检查有效性；缺失、损坏或过期时逐份读取旧记录并建立摘要，启动不填充详情缓存。摘要失败不使已成功的完整记录提交回滚。
- 内部修改复制记录壳、脚本壳与日志数组，复用不可变的已完成步骤证据；公共输入仍隔离。内部无需结果的调用可跳过完整返回值克隆。
- 进度先根据摘要判断变化，再脱敏与复制小进度载荷。同一运行步骤只保留最新待写进度，按 5 秒间隔合并；进度提交同步更新心跳，避免重复写。步骤完成、失败、制品与批次终态仍立即串行原子替换，保持 revision 与 updatedAt CAS。
- 失败进度继续保留用于重试，完成步骤和终态会丢弃旧待写进度。终态修正写入失败时保留最后已发布源记录，即便关闭详情缓存也不会把未确认的临时终态当成已发布结果；成功后释放。延迟的步骤开始登记不能回退已保存的步骤结果。
- 非流水线执行的脱敏历史副本成功保存后释放；流水线不再生成无人使用的第二份历史脱敏副本。原有执行结果快照 TTL、等待保存和重试语义保留。
- `GET /runner/resources` 提供 schemaVersion 1 分组指标。前端独立类型、校验、单位格式化与 `RunnerResourcesPanel` 按组渲染，便于新增指标。
- 资源页包含进程 RSS/峰值、CPU、启动时长、句柄、V8 堆与上限、external/ArrayBuffers、系统内存/CPU/负载、磁盘、活动容量与执行快照、历史/缓存、写入与索引状态、重要时间和采集限额。动态脚本模块导入仅增加累计尝试观测，没有改变原有每次加载新源码的规则。
- 仅页面首次打开与手动操作采集，移除该页 5 秒健康轮询。显示采样时间、采集中、接口失败、离线、过期快照及单组不可用。指标不包含环境凭据、命令行或任务载荷。
- 历史统计增量维护，资源采样不初始化历史、不遍历文件或加载详情；磁盘采样最多等待 250 ms。HTTP 响应禁止缓存，接口沿用本地 Origin 限制。

- 相关回归（含安装的 Google Chrome 的配置持久化与流水线刷新/关闭/恢复/停止）：145 项通过。后续核心修正另有上述最终复核。
- 前端：41 个测试文件、311 项全部通过，包含首次采样、无轮询、手动刷新、重复点击、超时、HTTP/格式错误、离线与过期快照恢复。
- `npm run typecheck` 与 `npm run build` 通过。构建仍提示已有体积较大的公共分包，未放宽阈值。
- 合成历史：80 份、84,061,690 字节；子进程堆上限 64 MiB。顺序索引后 GC 堆约 3.73 MiB，依次读取所有详情后约 5.67 MiB。2 MiB 缓存预算下留存 1 份约 1.00 MiB 详情，淘汰 79 次。重启/list/diagnostics/维护对已完成且有有效索引的历史不读取详情。
- 100 个并发进度更新合并为 1 次完整记录写入；间隔内保持最新脏进度，到期落盘；步骤完成后的迟到进度不能覆盖最终结果。
- 曾尝试根目录 `npm test`；长时间运行出现多处 Chrome 启动与 UI 稳定等待超时，并在后续页面响应测试停滞后中止本次自建测试进程。因此不把这次根命令记录为全量通过。失败用例原样做针对性复核，译文比较 19 项、导航/排序 20 项、提交/对话框/配额 13 项、大陆发布 1 项、页面响应 7 项均通过；剩余提交列表、网络等待、回复、上传和导航收尾复核 55 项全部通过，所有初次已报告失败的用例均在原样复核中出现通过记录（见 validation-summary.json）；根命令仍不记为完整通过。没有修改断言或译文例外来处理这些超时。
- 资源页 Chrome 端到端：初次请求为 health=1、resources=1，静置 6 秒不变；逐次手动刷新、离线、恢复和重开后合计各 5 次请求，业务执行请求 0。1440/900/390 宽度下页面 scrollWidth 均等于视口宽度，指标块溢出 0，pageerror 0。桌面、离线与窄屏截图已人工查看。

## 边界

首次旧历史索引和单条详情读取仍需解析一份完整记录，峰值取决于最大单条记录；详情缓存的字节是序列化体积，并非真实 JS 对象堆大小。常驻摘要随历史数量增长，未引入数据库或删除历史。

活动执行、尚未成功持久化的必要结果与终态重试源记录不能提前丢弃；资源页单独显示待保存和保留快照。既有动态 ESM 导入缓存与 Chrome 子进程资源没有在本次改为隔离进程，RSS 指标明确只包含 Runner Node 进程。

上述隔离验证没有读取真实 2.38 GB 历史做压力复现，也没有启动远端 TEST 七步批次；新实现先通过独立临时服务验证。后续在确认 Runner 空闲后正常重启，通过摘要索引加载真实历史，并顺序完成 TEST 七步冒烟与四步邮箱回归；结果、采集警告及资源释放证据见前述真实环境验证报告。
